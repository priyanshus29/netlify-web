# Project screenshots

Optional: add an authentic screenshot you own or have explicit permission to publish, using the project slug as the filename, for example `go-mobi.webp`, `tsi.png`, `arya.jpg`, `dynamic.webp`, or `moldmaster.jpg`. Supported extensions, checked in order: webp, png, jpg, jpeg. Run `npm run build` after adding or replacing an image. Images appear alongside the conceptual visualizations; they do not replace them.

Do not use screenshots containing credentials, confidential business data, sensitive personal information, private endpoints or client information you are not authorized to disclose. Add a descriptive `screenshotAlt` field to the corresponding project object in `data/content.json`; otherwise the build uses a generic alt description. For best performance, optimize images before adding them.
